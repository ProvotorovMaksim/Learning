# Технический обзор · Learning — примеры интеграций на Python

Оценка для позиции Junior Python Developer / Integration Engineer. Основание — статический анализ исходников, сохранённых в Git на коммите `84688a9`. Выводы о сценариях отказа требуют проверки в рабочем окружении.

## Сильные стороны

Отдельные скрипты показывают различия между транспортом, сериализацией и кэшированием. В примере Redis есть явное удаление ключа после изменения товара.

## Слабые стороны и архитектурные замечания

Адрес Redis в `RedisCache.py` пуст. Дополнительно стоит проверить логику обновления кэша при одновременном чтении и записи и поведение Avro при изменении схемы.

## Что проверить на демонстрации

Примеры не собраны в единое приложение. Для воспроизводимости нужны настройки подключения и минимальные инструкции по каждому сценарию.
